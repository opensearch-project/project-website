name: OpenSearch on Control Plane
description: An open-source Helm template that deploys a multi-node OpenSearch cluster with OpenSearch Dashboards on Control Plane. Security is on from the first boot (TLS on HTTP and transport, logins, audit log), credentials and the certificate authority come from platform secrets, and snapshots can be scheduled to Amazon S3 or Google Cloud Storage. Optional sample logs and a ready Security Analytics detector show findings with no setup.
