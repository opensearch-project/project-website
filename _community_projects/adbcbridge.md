---
name: adbcBridge
description: |
    Open-source driver for ADBC (Arrow Database Connectivity) that loads an ODBC driver and returns query results as Apache Arrow record batches. With the OpenSearch SQL ODBC driver it reads OpenSearch through the SQL plugin into Arrow from Python, Go, Rust, Java, and C#, so results go to pandas, Polars, or DuckDB without row-by-row conversion. Read-only, tested on Linux and Windows against OpenSearch 3.x.
